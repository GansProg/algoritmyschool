# Алгоритмдер және бағдарламалау · Алгоритмы и программирование

5–9 сыныптарға арналған төрт браузерлік информатика ойыны. Интерфейс қазақ (әдепкі) және орыс тілдерінде, жоғарғы жолда ҚАЗ / РУС ауыстырғышы бар.

Четыре браузерные игры по информатике для 5–9 классов. Интерфейс на казахском (по умолчанию) и русском, переключатель ҚАЗ / РУС в шапке.

Сайт: https://gansprog.github.io/algoritmyschool/ (после включения **Settings → Pages → Source: main, / (root)**).

| Ойын / Игра | Сынып / Класс | О чём |
|------|-------|-------|
| Робот-курьер | 5–6 | Программа из блоков «вперёд / налево / направо / повторить N раз / если стена». 10 уровней: линейные алгоритмы → циклы → ветвления → лабиринт по правилу правой руки. |
| Баг-аңшы / Баг-хантер | 7–9 | Программа робота на Python с ошибкой. Видно нужный маршрут и реальный, ошибку исправляют за ограниченное число правок. 8 багов. |
| Python-квест | 8–9 | «Ночь в музее»: каждое действие героя записывается строчкой кода. Python выполняется в браузере через Skulpt. 7 глав: функции, переменные, if/elif, for, while, списки, def. На казахском команды тоже казахские: `go("солтүстік")`, `press("сол")`. |
| Сұрыптау цехы / Сортировочный цех | 8–9 | Ящики по весу с лимитом ходов, пошаговая сортировка пузырьком и выбором, лаборатория для сравнения. |

## Іске қосу / Запуск

`index.html` файлын браузерде ашыңыз. Сервер керек емес. / Откройте `index.html` в браузере, сервер не нужен.

## Устройство

- `js/i18n.js` — словарь интерфейса на двух языках и переключение языка.
- `js/world.js` — клетчатый мир робота (общий для курьера и баг-хантера).
- `js/*-core.js` — уровни и логика каждой игры. Тексты уровней записаны парами `{ kk: '…', ru: '…' }`; новый уровень добавляется копированием соседнего.
- `js/courier.js`, `bugs.js`, `pyquest.js`, `sort.js` — интерфейс игр.
- `lib/` — Skulpt 1.2.0 (MIT, см. `lib/SKULPT-LICENSE`), подключён локально, чтобы Python работал без интернета.
- Оценки, выбранный язык и прогресс хранятся в `localStorage` браузера.

# Алгоритмы и программирование

Четыре браузерные игры по информатике для 5–9 классов. HTML, CSS и JavaScript без сборки и без сервера.

| Игра | Класс | О чём |
|------|-------|-------|
| Робот-курьер | 5–6 | Программа из блоков «вперёд / налево / направо / повторить N раз / если стена». 10 уровней: линейные алгоритмы → циклы → ветвления → лабиринт по правилу правой руки. |
| Баг-хантер | 7–9 | Программа робота на Python с ошибкой. Видно нужный маршрут и реальный, ошибку исправляют за ограниченное число правок. 8 багов: off-by-one, отступы, условие, if/while. |
| Python-квест | 8–9 | Текстовое приключение «Ночь в музее»: каждое действие героя записывается строчкой кода. Python выполняется в браузере через Skulpt. 7 глав: функции, переменные, if/elif, for, while, списки, def. |
| Сортировочный цех | 8–9 | Ящики расставляются по весу с лимитом ходов. Пошаговая визуализация сортировки пузырьком и выбором, лаборатория для сравнения. |

## Запуск

Откройте `index.html` в браузере. Сайт: https://gansprog.github.io/algoritmyschool/ (после включения **Settings → Pages → Source: main, / (root)**).

## Устройство

- `js/world.js` — клетчатый мир робота (общий для курьера и баг-хантера).
- `js/*-core.js` — уровни и логика каждой игры, без DOM. Новый уровень добавляется в массив `LEVELS` / `CHAPTERS`.
- `js/courier.js`, `bugs.js`, `pyquest.js`, `sort.js` — интерфейс игр.
- `lib/` — Skulpt 1.2.0 (MIT, см. `lib/SKULPT-LICENSE`), подключён локально, чтобы Python работал без интернета.
- Оценки и прогресс хранятся в `localStorage` браузера.

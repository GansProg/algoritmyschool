Четыре игры для 5–9 классов. Начинаем с команд роботу, заканчиваем сортировкой и настоящим Python. За каждый уровень учитель-программа ставит оценку.

Игры идут по возрастанию сложности

    Как ставятся оценки

    «5» за решение не длиннее эталонного, «4», если программа работает, но вышла длиннее или понадобилась подсказка. Оценки хранятся в этом браузере.

    Без сервера

    Всё работает прямо в браузере, Python тоже: его исполняет Skulpt. Сайт можно открыть с флешки или выложить на GitHub Pages.

    Учителю

    Уровни описаны в файлах js/*-core.js обычными массивами. Новый уровень добавляется копированием соседнего.
